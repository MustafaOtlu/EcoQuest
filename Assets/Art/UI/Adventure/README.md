# EcoQuest — illustrated game interface

Selected artwork from Kenney UI Pack Adventure, CC0. The exact upstream license is in License.txt.
Source: https://kenney.nl/assets/ui-pack-adventure

SVG files here are editable in Inkscape. Matching double-resolution PNG exports are in Assets/Resources/EcoUI/Adventure.
Only artwork used by the interface is included. No external plugin is needed at runtime.

The hero portrait in Resources is rendered from EcoQuest's existing player model, not from this pack.
Main cards use wood, paper and metal frames; gameplay status uses compact floating elements and detailed panels remain expandable.
